# Ask Prism UX Refinement Plan

## Summary
Implement a context-aware Ask Prism drawer experience that removes duplicate follow-up chips, replaces static portfolio context with page-aware context, and improves composer prominence and placeholder relevance.

## Key Changes
1. Welcome/follow-up deduplication
2. Dynamic context summary card by page and entry context
3. Stronger sticky composer + contextual placeholder
4. Intelligent navigation chips with current-route suppression
5. Follow-up queries always available after first turn
